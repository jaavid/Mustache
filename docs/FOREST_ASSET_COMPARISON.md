# Forest asset selection — final

## Decision

Two original Karsiori CC0 source assets, rather than the old three similar
procedural trees:

1. Oak #6, from [FREE Pixel Art Tree Pack](https://karsiori.itch.io/free-pixel-art-tree-pack) — 70×98 PNG.
2. Large night spruce, from [FREE Pixel Art Spruce Tree Pack - Animated](https://karsiori.itch.io/spruce-tree-pack-pixel-art-animated) — 25 × 74×128 frame sheet.

The 35×28 willow-like candidate was rejected, and is **not** shipped.
Position mapping is `cedar - oak - cedar`. Karsiori CC0 allows use and
modification in commercial products; attribution is retained voluntarily.

See [assets/forest/README.md](../assets/forest/README.md) for runtime assembly
and hit-alignment rules. Gameplay screenshot checks run in Playwright.
